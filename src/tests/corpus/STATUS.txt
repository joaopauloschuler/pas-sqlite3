#               db-blob differs in bytes covered by a documented
#               MASK.md range.  Tracked but non-blocking.  `cite`
#               must point at MASK.md (e.g. `MASK.md:offset=24`).
#   pas-skip    gated on an open Phase 6/7/8 bullet that the corpus
#               cannot legitimately exercise yet.  `cite` must name
#               the open tasklist bullet (e.g. `tasklist:6.26`).
#
# `cite`   citation token; must be non-empty for pas-soft / pas-skip
#          and must be `-` for pas-strict.
# `note`   one short clause (free text).
